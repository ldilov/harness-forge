# Claude Code runtime

Use the promoted language skills, `.specify/` flow, and shared release gates.

At the start of meaningful coding work, read `.hforge/runtime/agent-brief.md` before broad repository scans. Use `.hforge/generated/agent-command-catalog.json` and `/hforge-init` when you need an explicit Harness Forge session orientation.

For complex tasks, use `.hforge/library/skills/complex-task-protocol/SKILL.md`
automatically rather than waiting for a slash command. Keep the main agent on
the critical path, use no more than two bounded sidecar agents by default, and
require sidecar results to include evidence, files, risks, confidence, and
verification notes.
